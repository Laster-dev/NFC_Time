# 🌟 NFC_Time_NEO (全新重构版)

彻底摒弃 GitHub 依赖的本地化高性能 NFC 计时与智能结算系统。

---

## 核心重构与系统特性

### 1. 独立轻量后端服务
- **不再走 GitHub**：基于 ASP.NET Core (.NET 8) 构建高速本地 Web API，绑定 `http://0.0.0.0:5000`。
- **数据持久化**：卡片状态及操作毫秒级同步，自动持久化至 `server/data/cards.json` 与 `server/data/config.json`。
- **静态前端托管**：内置托管 Web 客户看板（`server/wwwroot/`），局域网内任意手机、平板、电脑扫码或输入 IP 即可实时查看。

### 2. 客户端后台管理与密码鉴权
- 进入「设置 / 卡片档案库 / 敏感管理」前，强制弹出管理员密码鉴权（默认密码：`888888`）。
- 支持在后台直接修改管理员密码。

### 3. 卡片生命周期与库管理
- **停止后再次启用自动开启全新计时**：卡片停止计时后历史状态完全重置，再次刷卡或开启时，自动作为全新会话开始计时。
- **卡片档案库彻底删除**：在「未使用卡片档案库」中可直接物理彻底删除卡片。

### 4. 客户类型与多维度标签
主界面实时高亮显示三大核心属性：
- 📟 **智能豆板标签**：显示当前是否使用智能豆板及对应套餐（`按小时` / `下午场` / `全天场`）。
- ⚠️ **付款方式标签**：
  - `⚠️ 玩完再付 (后付款)`（醒目红底标签，防漏单）
  - `✅ 先付款 (预付)`
- 📦 **预设套餐标签**：显示预设套餐（`1小时套餐` / `3小时套餐` / `上午场` / `下午场` / `全天场` / `双人3h` / `纯计时`）。

### 5. 灵活时间控制与中途开启智能豆板
- **设置/修改卡片开始时间**：支持补录已玩时间（如设置卡片在 5分钟前 / 15分钟前 / 30分钟前 开始）。
- **中途开启/关闭智能豆板**：在计时进行中随时可以点击「中途开启豆板」，系统精准按开启时刻单独累计豆板时长并自动结算。

### 6. 多维度计费与最优结算规则引擎
- **智能豆板计费**：
  - 1小时：5 元
  - 下午场：27.9 元 (14:00 - 19:30, 330分钟)
  - 全天场：33.9 元 (10:00 - 20:30, 630分钟)
  - 豆板超时：5 元 / 小时
- **游玩基础超时计费**：
  - 15分钟内免费缓冲
  - 超时 16~30 分钟：8 元
  - 超时 31~60 分钟：15 元
  - 超出整小时：每小时 15 元
- **最优价格推荐与明细生成**：
  - 预设套餐：基价 + 游玩超时加时 + 智能豆板费用。
  - 玩完再付：全场套餐方案自动比对，匹配**最低总价**，并以分步公式展示计算过程。

### 7. 智能语音播报过滤
- 仅对「先付款」普通倒计时卡片播报到期/超时预警；
- **固定场次套餐（上午场、下午场、全天场）免打扰不播报**；
- **玩完再付 / 后付款客户免打扰不播报**。

## 目录结构

```
NFC_Time_NEO/
├── android/               # Android App 原生客户端源码
│   ├── app/build/outputs/apk/
│   │   ├── debug/app-debug.apk      # 调试版 APK
│   │   └── release/app-release.apk  # 签名发布版 APK
├── server/                # C# .NET 8 Web API 后端及数据持久化
│   ├── Controllers/       # Cards, Auth, System 控制器
│   ├── Services/          # CardManager, PriceCalculator, AuthService
│   ├── Models/            # CardInfo, Pricing Models
│   ├── data/              # cards.json, config.json 数据持久化目录
│   └── wwwroot/           # 客户看板 Web 静态文件 (HTML/CSS/JS)
├── voice_service/         # Python Edge-TTS 智能语音播报服务
├── build_android_apk.bat  # 一键重新编译 APK 脚本
├── start_server.bat       # 启动后端服务 (http://localhost:5000)
├── start_voice.bat        # 启动语音播报服务
└── run_all.bat            # 一键全系统启动脚本
```

## 快速使用说明

1. 双击运行 `run_all.bat`：
   - 自动启动后台服务（端口 5000）；
   - 自动启动智能语音播报服务；
   - 自动打开浏览器看板展示页（`http://localhost:5000`）。
2. 在 Android 手机上安装 `android\app\build\outputs\apk\release\app-release.apk`。
3. 手机进入 App 设置界面（需输入管理员密码 `888888`），配置电脑后端的局域网 IP（例如 `http://192.168.1.100:5000`），即可直接刷卡使用！
